第1章 绪论
1.1 研究背景
当前，新型冠状病毒肺炎疫情对中国高校毕业生的就业产生了深刻的影响。为确保广大毕业生的就业得到切实的保障，学校、企业和学生都开始使用线上招聘。如今，线上应聘、招聘成为多数毕业生和用人单位的首选形式[1]。
虽然线上招聘已经成为大学生求职的主要途径，但其发展仍存在一些问题。一些不良企业可能会发布虚假的信息，诱骗求职者上当受骗；有些网络招聘平台的用户体验不佳；有些招聘平台对企业审核不严格，导致平台出现大量不良企业[1]。
1.2 研究意义
在当前就业形势日益严峻的情况下，校园招聘已成为企业引进人才的重要途径[2]。然而，随着企业对校园招聘的需求和竞争的日益激烈，校园招聘也面临一系列的挑战和问题。由于企业未根据实际需求进行招聘、大学生职业规划不清晰、高校时间安排不合理、企业缺乏高效的招聘系统等原因，校园招聘出现了一些突出问题，如企业集中招聘、高校招聘时间冲突、大学生择业犹豫等[2]。因此，我们需要探索更加科学、高效的校园招聘模式，以满足企业和大学生的诉求，促进校企合作和人才培养。
据了解，国内招聘系统基本只关注职位信息，而且有些招聘平台出现不实招聘信息。所以本项目将校园招聘回归校园，以学校和毕业生为主体，杜绝不实招聘信息，促进毕业生顺利就业。
第2章 开发技术
2.1 Spring Cloud技术栈
Spring Cloud是一个基于Spring框架构建的云原生应用开发解决方案。它是一个非常流行的开源框架，提供了一系列工具，用于开发和管理微服务应用程序，并实现了许多微服务应用程序需要的基础功能，如服务注册、服务调用、负载均衡等等[3]。此外，Spring Cloud提供了一些常用组件，它们可以集成在Spring Boot应用程序中，为开发者更好地管理和实现微服务架构中需要的功能提供了极大的便利[4]。因此，Spring Cloud是一个非常好用的微服务应用开发框架，可以帮助开发人员更好地构建和管理微服务架构的应用程序。
2.2 Spring Cache缓存框架
Spring Cache是Spring提供的一个基于注解的缓存框架，使用方便，可提高系统性能。Spring Cache可以与各种缓存技术集成（如Redis），开发者可以根据需要选择合适的缓存技术。Spring Cache封装了底层缓存框架的细节，提供了一种方便、简单的方式来对缓存进行操作，开发者只需要在代码中添加相应的注解即可轻松地实现缓存功能，简化了缓存的操作。通过缓存机制，可以避免频繁地从数据库或其他存储介质中读取数据，加快系统的访问速度，减轻服务器的压力，提高系统的吞吐量和并发性能。
2.3 kkFileView在线文件预览
kkFileView是一个基于Spring Boot框架开发的文件文档在线预览解决方案。通过集成kkFileView，可以方便地在Web应用程序中实现对各种文件格式的在线预览功能，如Word、Excel、PowerPoint、PDF、文本、压缩文件以及图片、视频、音频等多种类型的文件。在使用kkFileView的过程中，不需要任何插件或客户端软件的支持，用户只需在浏览器中打开相应的文件即可。同时，kkFileView使用了高效的异步加载和缓存技术，能够快速地加载和渲染大型文件，保证预览效果流畅自然。kkFileView还支持多种文件上传方式，包括本地上传、FTP上传、OSS上传等，用户可以根据实际需求选择适合自己的方式。在将kkFileView集成到项目中时，开发者只需要引入相关依赖并配置一些参数即可，非常方便。kkFileView的API也非常简单易懂，开发者可以很快地掌握并使用kkFileView的各种功能。
总之，kkFileView是一个功能丰富、易于集成、高效稳定的文件文档在线预览解决方案，广泛应用于各种Web应用程序中，能够大大提高用户体验和开发效率。

3.2 可行性分析
3.2.1 技术可行性
本系统使用Spring Cloud Alibaba技术栈，将系统细分为多个服务，服务之间相互独立。这种架构使得系统能够应对大量请求，并且可以动态调整系统性能。此外，系统各模块之间的耦合度较低，当某模块业务需求改变时，开发人员可以针对性的修改该服务，而不会影响系统的整体运行，从而实现系统的平滑升级。
综上所述，采用Spring Cloud Alibaba技术栈实现校园招聘系统具有较高的技术可行性，可以构建一个较好的招聘系统，满足学校、企业和学生的需求，促进校园招聘行业的发展。
3.2.2 经济可行性
本系统可以在无需重启整个系统的情况下实现单个服务的升级和更新，这可以大幅提高运维效率，从而节省运维成本；校园招聘系统采用微服务架构，可以更加灵活地响应用户需求，快速定位和解决问题。同时，通过微服务的自治性和独立性，避免了一个问题影响整个系统，提高了用户满意度。
总之，校园招聘系统在经济可行性方面具有较高的优势，可以帮助企业通过降低开发成本、提高运维效率、增强系统的可扩展性、提高用户满意度等多方面实现成本控制和风险管理。
第4章 概要设计
4.1 业务流程设计
本系统将用户划分为学校、学院、专业、学生、企业等角色，用户通过统一的登录界面登录。
学校用户进入系统后，可以对本校的二级学院进行管理。用户可以查询学院信息、新增学院、删除学院和修改学院信息，此外还支持Excel文件的导入和导出。
学院用户进入系统后，能够进对申请入驻的企业进行资质审查、审核企业发布的招聘信息、增删改专业信息、通过Excel文件导入专业等。
具备专业角色的用户登录系统后，可以对该专业下的班级和学生进行管理，能够进行新增、修改、删除和批量导入等功能，主要是进行毕业生信息的管理。
学生进入系统后，可以管理简历、求职、查看投递记录、分享面试经验。学生管理简历时，可以选择上传pdf等常用文件格式的简历，也能够创建在线简历，完善简历信息后，可以对简历进行预览操作。学生求职时，可以先浏览多个职位信息的简要信息，点击指定职位后展示其详细信息，学生找到心仪岗位后可以投递简历。此外，学生还可以撰写面试经验并分享。系统会记录每一次投递记录，并将投递记录以时间线的方式可视化展示。
企业用户首先得提交入驻申请，待申请通过后便会收到包含账号和初始密码的邮件，企业用户通过该账号即可登录系统。用户进入系统后，可在个人中心修改初始密码。企业用户能够使用文档编辑器编辑招聘信息，编辑完成后即可提交审核，待审核通过后便可展示。此外，企业用户可以对收到的简历进行处理、安排面试或笔试计划。
4.2 业务架构设计
本系统按照业务流程分为学校端、学生端和企业端三个子系统，学校、学院、专业三个角色的用户属于学校端，学生角色的用户属于学生端，企业角色的用户属于企业端。学校端子系统业务主要有：学院管理、企业入驻管理、招聘信息审核、专业管理、班级管理、学生管理。学生端子系统主要业务有：上传附件简历、创建在线简历、求职、分享面试经验、查看投递记录。企业端子系统业务功能主要有：招聘信息管理、投递处理、笔试安排、面试安排。系统业务架构图如图7所示。

# controller
@PostMapping("/sendNotice")
public AjaxResult sendNotice(@RequestBody Examination examination) {
    examinationService.notified(examination);  // 更新为已通知状态
    //获取需要通知的邮箱列表
    List<String> tos = examinationService.getEmail(examination); 
    if (tos.size() != 0) {  // 邮箱列表不为空
        examinationService.send(tos, examination);  // 发送邮件
    }
    return AjaxResult.success("已通知" + tos.size() + "位应聘者");  // 返回响应信息
}
# service
@Override
public void notified(Examination examination) {
    examination.setNotifiedFlag("1"); // 设置状态为已通知
    examinationMapper.notified(examination); // 更新为已通知状态
}
@Override
public List<String> getEmail(Examination examination) {
    List<String> tos = new ArrayList<>(); // 发送列表，保存需要通知的邮箱
    // 查询当前岗位已通过简历初筛的学生
List<Long> studentList = examinationMapper.agreedStudentId(examination.getPostId());
    // 获取学生的邮箱
    if (!studentList.isEmpty()) {
        List<Map<String, String>> maps = examinationMapper.studentEmail(studentList);
        for (Map map : maps) {
            if (!tos.contains((String) map.get("email"))) { // 判断发送列表中是否已存在该邮箱，防止重复发送
      tos.add((String) map.get("email")); // 将当前学生的邮箱添加到计划返回的列表中
            }
        }
    }
    return tos; // 返回需要通知的邮箱列表
}
@Async("taskExecutor")
@Override
public void send(List<String> tos, Examination examination) {
    MailUtil.send(tos, examination.getName(), examination.getNotice(), true);  // 使用HuTool工具类发送邮件
}

        ThreadPoolTaskExecutor executor = new ThreadPoolTaskExecutor();
        executor.setCorePoolSize(10);  //设置核心线程数
        executor.setMaxPoolSize(20);  //设置最大线程数
        executor.setQueueCapacity(200);  //缓冲队列200 
        executor.setKeepAliveSeconds(60);  //线程活路时间 60 秒
        executor.setThreadNamePrefix("taskExecutor-");  //线程池名的前缀
        executor.setRejectedExecutionHandler(new ThreadPoolExecutor.CallerRunsPolicy());  //设置拒绝策略
        executor.setWaitForTasksToCompleteOnShutdown(true);
        return executor;
    }
}
