## Why

当前平台只有"手动选股 → 分析 → 下单 → 盯盘 → 手动卖出"这一条单一流程，用户必须时刻盯盘并手动操作。这限制了平台从"模拟交易工具"升级为"智能投资平台"的能力。增加条件单、自选股+价格预警、策略回测三项功能，可以让用户实现"不盯盘自动交易 → 主动关注机会 → 验证交易策略"的完整投资闭环。

## What Changes

### 1. 条件单（止盈止损）
- 新增止盈单类型：用户设定目标价格，股价达标时自动卖出
- 新增止损单类型：用户设定止损价格，股价跌破时自动卖出
- 条件单触发引擎：定时轮询行情数据，检测触发条件并自动执行
- 条件单管理：查看、编辑、取消待触发的条件单

### 2. 自选股 + 价格预警
- 新增自选股（关注列表）：用户可添加/移除关注的股票
- 新增价格预警：用户设定预警价格和方向（向上突破/向下跌破）
- 预警通知：价格触发时在系统内推送通知
- 自选股行情面板：集中展示自选股实时行情

### 3. 策略回测
- 策略模板：预设经典策略（均线交叉、动量突破等）
- 回测引擎：基于历史 K 线数据模拟交易
- 回测结果：收益曲线、收益率、最大回撤、胜率、夏普比率
- 回测报告：可视化图表展示买卖点

### 数据库变更
- 新增 `conditional_orders` 表：条件单
- 新增 `watchlist` 表：自选股
- 新增 `price_alerts` 表：价格预警
- 新增 `backtest_strategies` 表：回测策略定义
- 新增 `backtest_results` 表：回测结果
- 修改 `orders` 表：增加条件单关联字段

## Capabilities

### New Capabilities
- `conditional-orders`: 止盈止损条件单的创建、管理、触发执行
- `watchlist`: 自选股关注列表的增删改查和行情展示
- `price-alerts`: 价格预警的创建、监控和通知推送
- `strategy-backtesting`: 策略定义、历史数据回测、结果可视化

### Modified Capabilities
- `stock-trading`: 订单系统新增条件单类型，订单表支持条件单关联

## Impact

- **数据库**: MySQL 新增 5 张表，修改 1 张表（orders）
- **后端服务**:
  - `trading-service`: 扩展订单服务，新增条件单 CRUD 和触发引擎
  - `market-service`: 新增自选股服务、价格预警监控服务
  - `analysis-service`: 扩展为分析+回测服务，新增回测引擎
  - `user-service`: 无需变更
  - `portfolio-service`: 无需变更
- **前端**: Vue 3 新增 4 个一级页面（条件单管理、自选股、价格预警、策略回测）
- **网关**: 新增对应的路由规则
- **API**: 新增约 20 个 REST 端点
